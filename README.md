# CIS121 – Introduction to C++ Programming (Fall 2025)

## Overview

This repository contains my coursework for **CIS121 – Introduction to C++ Programming** at Triton College.

Throughout the semester, I learned the fundamentals of C++ programming and progressively built more complex programs involving functions, arrays, vectors, file processing, structures, and object-oriented programming. These assignments established the programming foundation that I later applied in Data Structures (CIS225).
